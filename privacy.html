개인정보처리방침

문서 작성일: 2026년 10월 4일

Reservation & Customer Management System(RCMS)의 매장 PC 실행형 프로그램과 Google·Discord 연결에 적용되는 데이터 처리 원칙입니다. 각 매장 운영자는 자신이 등록한 고객 정보와 연결 계정의 접근 권한을 관리합니다.

1. 처리하는 정보와 목적

정보이용 목적
고객 이름·연락처·안내 동의·운영자가 입력한 특이사항고객 식별, 예약 관리, 동의한 고객의 재시술 안내 대상 관리
예약·시술·결제·회원권·매출 내역예약 처리, 시술 완료 기록, 회원권 사용 및 매출 집계
선택한 Google 스프레드시트의 식별자·파일명·업무 시트 내용업무 데이터 조회·기록, 데이터 정합성 점검 및 갱신
설정된 Google Calendar의 예약 일정·이벤트 식별자예약 일정 생성·조회·수정·삭제 또는 완료 상태 반영
Google OAuth 인증정보 및 Discord 사용자·서버·채널 식별자승인된 API 접근 유지와 운영자 권한 확인
업무 복구 기록·처리 결과·오류 및 운영 로그미완료 업무 복구, 장애 확인 및 운영 이력 관리

2. Google 권한과 이용 범위

Google 계정 연결 시 아래 권한을 요청합니다. Sheets 권한은 계정이 접근 가능한 스프레드시트에 대한 권한이며, RCMS의 업무 대상은 운영자가 지정한 스프레드시트입니다. Calendar 권한은 일정에 대한 권한이며, 프로그램은 설정된 캘린더의 RCMS 예약 일정을 관리합니다.

  • https://www.googleapis.com/auth/spreadsheets: 업무 시트 읽기·쓰기와 연도 매출 시트 등 필요한 시트 생성
  • https://www.googleapis.com/auth/calendar.events: 예약 일정 읽기·생성·수정·삭제 및 완료 표시

Google API에서 받은 정보는 위 예약·고객·회원권·매출 기능과 해당 기능의 복구를 위해 이용합니다. Google 사용자 데이터를 판매하거나 광고 타기팅, AI 모델 학습에 이용하지 않습니다.

RCMS의 Google API 정보 이용 및 다른 서비스로의 전송은 Google API Services User Data Policy의 Limited Use 요구사항을 준수합니다.

3. 보관 위치와 기간

  • 업무 데이터는 운영자가 지정한 Google Sheets와 Google Calendar에 저장됩니다. 로컬 Excel 방식으로 운영하는 경우 지정한 Excel 파일에도 저장됩니다.
  • Google 연결정보와 갱신 토큰은 프로그램이 실행되는 매장 PC에 저장됩니다. 인증정보는 서비스 실행 계정의 파일 접근 권한으로 보호되며 파일 자체를 별도로 암호화하는 방식은 아닙니다.
  • 복구에 필요한 업무 내용은 매장 PC에 임시 기록됩니다. 정상 처리 완료 시 해당 업무 복구 파일을 삭제하며, 미완료 기록은 복구·확인에 필요한 동안 유지됩니다.
  • 업무 데이터, 연결정보, 운영 로그 및 Discord 이력은 각 저장 위치의 설정과 매장 운영자의 보관·삭제 정책에 따라 유지됩니다. 전체 업무 데이터가 자동으로 일괄 삭제되는 보관 기한은 설정되어 있지 않습니다.

4. 정보 전달과 접근

Google에는 API 처리를 위해 해당 업무 데이터를 전송합니다. Discord에는 명령 입력 내용과 처리 결과, 권한 확인 및 운영 이력에 필요한 정보를 전달합니다. 고객 표시명이나 예약·매출 정보가 포함된 메시지는 매장이 설정한 채널 접근 권한에 따라 운영자가 볼 수 있습니다.

RCMS 제공자가 운영하는 별도의 중앙 고객정보 수집 서버는 없습니다. 프로그램 지원 과정에서 데이터 확인이 필요한 경우 매장 운영자가 확인 범위와 제공 여부를 결정합니다. Google 사용자 데이터에 대한 사람의 접근은 사용자 동의 또는 Google 정책이 허용하는 보안·법적 사유 등으로 제한합니다.

안내 페이지의 호스팅 제공자인 GitHub는 방문 요청에 따른 기술 정보를 자체 정책에 따라 처리할 수 있습니다. 이 안내 페이지에는 별도의 회원가입, 데이터 입력 폼, 분석·광고 스크립트가 없습니다. GitHub 개인정보처리방침을 참고해 주세요.

5. 권한 철회와 삭제 요청

  • Google 계정의 서드 파티 연결 관리에서 RCMS OAuth 앱의 연결을 삭제해 Google 접근 권한을 철회할 수 있습니다.
  • 권한 철회는 기존 Sheets·Calendar 데이터나 매장 PC에 저장된 파일을 자동 삭제하는 작업이 아닙니다. 전체 이용을 종료할 때는 프로그램을 중지한 뒤 저장된 인증·연결정보와 불필요한 복구 기록을 삭제하고, Sheets·Calendar·Discord 데이터 및 운영 로그도 필요한 범위에서 정리합니다.
  • 매장 고객의 정보 열람·정정·삭제 요청은 해당 매장 운영자에게 접수합니다. RCMS 프로그램과 연결정보 처리 문의는 아래 지원 연락처로 요청할 수 있습니다.

6. 보호 조치와 변경 안내

Google API 통신에는 HTTPS를 사용하고, Discord 명령 실행에는 지정된 운영자·서버·채널 검사를 적용합니다. 매장 운영자는 PC 계정, 스프레드시트 공유 권한, 캘린더와 Discord 채널 권한을 관리해야 합니다.

데이터 처리 방식이 변경되면 이 페이지와 프로그램 안내를 갱신합니다. Google 데이터의 이용 목적이나 권한이 변경되는 경우 변경 내용을 안내하고 필요한 동의를 받습니다.
